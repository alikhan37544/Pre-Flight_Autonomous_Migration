About PreFlight

An offline, evidence-first cloud-readiness review product for Guidewire-style legacy estates. Independent research prototype.

What it is

PreFlight assembles feature candidates across PCF, entity metadata, typelists, extracted templates, Gosu, and Cloud API configuration; links every claim to file evidence; surfaces documented blockers and gaps; and produces a reviewable local Cloud API extension draft plus an impact-rated assumption register for one feature slice.

What it is not

  • It does not convert products to APD and does not replace Cloud Retrofit.
  • It does not produce an official Cloud Assurance result, score, or certification.
  • Not a generic Gosu linter; SonarQube and Cloud Assurance own generic linting.
  • Not a live-tenant connector or deployment tool.
  • The Migrator is an autonomous draft generator: it writes a local, non-deployable bundle and leaves every change pending human approval. It does not connect to a tenant or deploy code.

Plain-language glossary

Written for a reader with no Guidewire or cloud-migration background.

Evidence link
A reference from a claim to the exact file and line or pointer it came from, so a reviewer can check the source.
Feature
A named piece of insurance functionality, such as vehicle information on a policy, that PreFlight follows from screens and data definitions through code and tests.
Disposition
The recorded decision about a finding or mapping: accept, reject, edit, or defer, with a written reason.
Assumption
A named unknown or judgement call, with an impact rating and an owner, used when evidence is missing instead of quietly guessing.
Gate
A checkpoint that stays with a named human owner. A green machine check does not close a human gate.
SARIF
A standard JSON report format for static-analysis findings, so developer tools and code-scanning dashboards can display them.
Gosu
Guidewire's programming language for product rules and business logic. It is written code, not a visual product model.
APD
Guidewire's cloud product-definition system. PreFlight reviews readiness but does not convert products into APD.
Gosu Query / application API
The supported synchronous cloud read path for in-app code, replacing direct database or JDBC queries.
Cloud Data Access (CDA)
A streaming/export service to S3 Parquet for analytics and export; it is not the synchronous in-app read path.
App Events
Guidewire's cloud event mechanism, replacing legacy message queues such as JMS or MQ.
